# Kebijakan Privasi: Lokara

*Terakhir diperbarui: 13 November 2026*

Lokara adalah aplikasi pribadi untuk satu pengguna, dioperasikan oleh pemiliknya sendiri (GitHub: [@handokoaji](https://github.com/handokoaji)). Aplikasi ini tidak tersedia untuk umum dan tidak memiliki pengguna lain.

## Data yang diakses
- Postingan Threads yang **bersifat publik** dan cocok dengan kata kunci pencarian properti (rumah dan tanah dijual).
- Identitas dasar akun pemilik, hanya untuk otorisasi akses ke API.

## Data yang disimpan
- Ringkasan hasil pengolahan: judul, harga, luas, lokasi, dan tautan ke postingan asli.
- Teks lengkap postingan tidak disimpan. Data mentah dihapus setelah diproses.
- Token akses disimpan di server pribadi pemilik dan tidak dibagikan.

## Penggunaan data
- Hanya untuk membantu pemilik menemukan dan membandingkan properti.
- Data tidak dijual, tidak dibagikan kepada pihak lain, tidak dipakai untuk iklan, dan tidak dipakai untuk melatih model apa pun.

## Penghapusan data
Pemilik dapat menghapus semua data terkait kapan saja. Untuk permintaan penghapusan data atau pencabutan akses, buka *issue* di [github.com/handokoaji/handokoaji.github.io](https://github.com/handokoaji/handokoaji.github.io/issues) atau hapus aplikasi dari **Settings → Account → Website permissions** di Threads. Akses aplikasi akan berhenti dan data terkait dihapus.

## Perubahan kebijakan
Kebijakan ini dapat diperbarui. Tanggal pembaruan terakhir tercantum di bagian atas halaman.
