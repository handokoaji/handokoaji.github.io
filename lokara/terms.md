# Ketentuan Layanan: Lokara

*Terakhir diperbarui: 13 November 2026*

Lokara adalah aplikasi pribadi untuk satu pengguna, dioperasikan oleh pemiliknya sendiri (GitHub: [@handokoaji](https://github.com/handokoaji)). Aplikasi ini tidak ditawarkan kepada publik, tidak memiliki pengguna lain, dan tidak dipungut biaya.

## Tujuan
Membantu pemilik mencari dan membandingkan informasi properti (rumah dan tanah) dari sumber yang diakses secara sah, termasuk postingan publik di Threads melalui API resmi Meta.

## Ketentuan penggunaan
- Aplikasi dipakai hanya oleh pemiliknya, untuk keperluan pribadi dan non-komersial.
- Akses ke Threads hanya memakai API resmi dan izin yang diberikan akun pemilik. Batas laju dan kebijakan platform dipatuhi.
- Data tidak dijual, tidak dibagikan, dan tidak dipublikasikan ulang.

## Tanpa jaminan
Informasi properti (harga, lokasi, legalitas) berasal dari iklan pihak ketiga dan **tidak diverifikasi**. Aplikasi disediakan apa adanya tanpa jaminan apa pun. Keputusan membeli adalah tanggung jawab pemilik, dan pemilik wajib memeriksa legalitas sendiri.

## Data dan privasi
Pengelolaan data dijelaskan di [Kebijakan Privasi](./privacy).

## Pencabutan akses
Akses aplikasi ke akun Threads dapat dicabut kapan saja lewat **Settings → Account → Website permissions** di Threads. Permintaan lain dapat diajukan lewat [issue GitHub](https://github.com/handokoaji/handokoaji.github.io/issues).
